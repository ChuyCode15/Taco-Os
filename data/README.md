# Directorio de Data Science — Taco-Os
### Área: Ingeniería de Datos | Data Scientist: Leandro Puebla Martinez

Este directorio contiene los activos metodológicos, las bitácoras de investigación y los sets de datos físicos utilizados para alimentar el cerebro predictivo del POS gastronómico.

## Contenido Estructurado
*   **`data/notebooks/01_generacion_datos.ipynb`**: Cuaderno de Jupyter que actúa como bitácora científica de experimentos. Contiene el algoritmo de simulación estocástica y la generación elástica de la demanda comercial.
*   **`data/ventas_simuladas.csv`**: El dataset físico definitivo saneado con los 12.000 registros omnicanal indexados por la cabecera homologada.
*   **`data/Docs/DATA TASK 001.md`**: Especificación técnica exhaustiva de requerimientos y diccionario de datos de las variables.
